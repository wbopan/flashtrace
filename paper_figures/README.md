# FlashTrace paper figure reproduction

This directory is the auditable reproduction package for every data-bearing figure referenced by the current TPAMI manuscript at `/Users/wenbopan/Repos/flashtrace/icml-flashtrace-tpami`.

It deliberately separates measured data from synthetic, interpolated, missing, and placeholder values. The published figure PDFs are not overwritten; all rebuilt artifacts go to `paper_figures/output/`.

From `/Users/wenbopan/Repos/flashtrace`:

## Visual style

The quantitative plots share the semantic palette defined in
`scripts/common.py`:

- blue for input, baseline, or AttnLRP;
- green for FlashTrace;
- orange for reasoning or perturbation methods;
- red, purple, and neutral gray for the remaining method families;
- `#EDEFFB` for occasional background emphasis. This is the paper table's
  `cyan!10` highlight (`#4F5BD5` mixed with 90% white).

Every quantitative subplot uses a complete four-sided axis frame. Top and
right tick marks remain disabled so the frame does not add visual noise.
Multi-panel quantitative figures use square (1:1) plotting boxes for each
subplot; the overall figure remains wide enough to preserve the panel sequence.

The recovered MoreHopQA and Variable Tracking data are used by default. To test
another compatible processed-data tree:

```bash
uv run --project paper_figures python paper_figures/scripts/build_available.py \
  --morehopqa-data-root /path/to/processed/data
```

## Build or restyle one figure

```bash
uv run --project paper_figures python paper_figures/scripts/plot_pilot.py \
  --data paper_figures/data/pilot.json \
  --output paper_figures/output/time_plot.pdf

uv run --project paper_figures python paper_figures/scripts/plot_efficiency.py \
  --data paper_figures/data/efficiency.json \
  --output paper_figures/output/cost_comparison.pdf

uv run --project paper_figures python paper_figures/scripts/plot_reasoning_length.py \
  --data-root paper_figures/data/recovered_proc_1 \
  --output paper_figures/output/cot_faithfulness.pdf

uv run --project paper_figures python paper_figures/scripts/plot_mass_shift.py \
  --input-dir paper_figures/data/recovered_proc_1/morehopqa/qwen-8B/ifr_multi_hop_both_n3 \
  --output paper_figures/output/dist_fig.pdf
```

## Provenance boundaries that matter before redrawing

- `pilot.json`: the bars are measured from one short-CoT and one long-CoT example. The right scaling curve was generated by fixed formulas, seed 42, and Gaussian noise; it is not a runtime experiment.
- `efficiency.json`: `null` means not measured, `"oom"` means observed OOM. Generation-memory points at 1K and 2K for IFR, AttnLRP, and FlashTrace are legacy interpolation. The Pareto panel is not a direct transform of the time arrays; its speed axis was hand-normalized, and IG/IG-Attn faithfulness values were placeholders.
- `cot_faithfulness.pdf` and `dist_fig.pdf`: the source is the Git-tracked
  `exp/proc_1/output/data.zip` from commit `075e7e4`, not values digitized from
  the published PDFs. Its SHA-256 is
  `44666abac156848c095fe141d913afc96370fd090ed0c2994df6dfa912c826ba`.
  See `data/recovered_proc_1/PROVENANCE.md` for counts and recovery evidence.
